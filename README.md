🧮 Smart Calculator in Python
📌 About the Project

The Smart Calculator is a Python-based project that performs basic mathematical operations and advanced calculations using built-in Python libraries. It includes separate functions for each operation, making the code easy to understand, maintain, and extend.

✨ Features
Addition
Subtraction
Multiplication
Division
Square Root
Power Calculation
Factorial
Sine, Cosine, and Tangent
Logarithm (base 10)
Percentage Calculator
Average Calculator
Circle Area Calculator
Compound Interest Calculator
🛠️ Technologies Used
Python — Main programming language
math — Mathematical operations, trigonometry, and circle calculations
statistics — Calculating the average of numbers

⚙️ Requirements
Python 3.8 or later
No external package installation is required.

The math and statistics modules are included with Python.

🚀 How to Run
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:
bash
python smart_calculator.py

Select an operation from the menu.
Enter the requested values.
To close the calculator, select the Exit option.
